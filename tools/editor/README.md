# Внесение данных PokeMatrix

`public/editor.html` — **один самодостаточный файл**. Открываешь двойным
кликом с диска (без сервера, без интернета) — и правишь.

## Как это работает

1. Открываешь файл в браузере.
2. Выбираешь локацию / магазин из списка — **форма уже заполнена текущими
   данными из игры** (энкаунтеры, день/ночь, уровни, дропы, состав, цены).
3. Правишь: фишки со списком (✕ убрать, поле+кнопка добавить), слайдеры
   шансов, цены. Видишь шанс каждого вида в этой локации (в %).
4. Вкладка «✅ Что изменилось» показывает все правки русским языком.
5. **«💾 Сохранить в файл»** — скачивается копия страницы, где твои правки
   уже внутри (блок `pokematrix-data`).
6. Присылаешь мне этот html — я читаю правки из него и вношу в код.

## Что покрыто

| Вкладка | Что правится в игре |
|---|---|
| 🗺 Локации | энкаунтеры (общие/день/ночь), уровни, дропы видов (`src/data/regions.ts`, `src/data/drops.js`) |
| 🏪 Магазины | состав, цены (`src/data/shops.ts`, `server/src/routes/economy.ts`, `src/data/items.ts`) |
| 💰 Цены | цены всех предметов, клиентские и серверные |
| ✅ Что изменилось | список правок по-русски, текст для копирования, сохранение в файл |

## Обновление данных

В файл вшиты **текущие данные игры** (генератором ниже). Если в коде что-то
поменялось — пересобери:

```
npm run editor
```

Генератор (`tools/editor/gen-editor.mjs`) только **читает** исходники и
вшивает слепок в html. Код игры он не трогает. Правки в код вношу я вручную.
