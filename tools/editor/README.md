# Редактор данных PokeMatrix

Страница `public/editor.html` — ручной редактор игровых данных. Ты вносишь
правки в браузере, экспортируешь файл и присылаешь его — **в код я вношу
вручную**. Автоматического применения нет намеренно: скрипт, пишущий в
исходники, легко ломает форматирование и данные.

## Как пользоваться

1. Открой в браузере `https://<твой-домен>/editor.html`
   (локально: `npm run editor:gen`, затем открой `public/editor.html`).
2. Вкладки:
   - **🗺 Локации** — список локаций, у каждой: общий список энкаунтеров,
     отдельные списки «днём» и «ночью», диапазон уровней, механика (башня/пещера),
     ссылки, «не ловится», дропы видов этой локации.
   - **🎁 Дропы** — что падает с конкретного вида: предмет, шанс, количество.
   - **🏪 Магазины** — состав маркета: убрать ненужный предмет, добавить,
     задать цену.
   - **💰 Цены** — цены предметов: серверная (авторитетная) и клиентская.
3. В каждой вкладке есть поле **«📝 Заметка для меня»** — пиши туда словами,
     что именно нужно сделать. Это главная часть: по разметке я пойму замысел,
     по числам — точные значения.
4. Внизу **«⬇ Экспорт правок (JSON)»** → файл `pokematrix-patch.json`.
   Или **«📋 Скопировать в чат»** → вставь в сообщение.
5. Отправь мне файл/текст — применю.

## Что покрыто

| Что | Где в коде |
|---|---|
| Локации, энкаунтеры (день/ночь/общий), уровни | `src/data/regions.ts` |
| Дропы по видам | `src/data/drops.js` |
| Состав магазинов, тиры, исключения | `src/data/shops.ts` |
| Цены предметов (клиент) | `src/data/items.ts` |
| Цены предметов (сервер, авторитет) | `server/src/routes/economy.ts` |

## Пересборка справочника

Если данные в коде изменились (я что-то поправил) — обнови JSON:

```
npm run editor:gen
```

Генератор только **читает** исходники и пишет `public/editor-data.json`.
Ничего в коде он не меняет.
