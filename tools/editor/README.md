# Внесение данных PokeMatrix

`public/editor.html` — **один самодостаточный html-файл**. Открыл его с диска
(двойным кликом) — и работаешь. Ни сервера, ни интернета, ни зависимостей.

## Как это работает

1. Открываешь `public/editor.html` в браузере.
2. Заполняешь форму **по одному** (одна локация / один магазин / одна цена).
3. Нажимаешь «➕ Добавить в список» — запись появляется в списке внизу.
4. **«💾 Сохранить в файл (html)»** — скачивается копия страницы, в которой
   твои правки уже записаны внутрь (блок `<script id="pokematrix-data">`).
5. Присылаешь мне этот html — я читаю правки прямо из него и вношу в код.

Правки лежат **в самом файле**, а не в браузере: можно закрыть вкладку,
переоткрыть файл — всё на месте. Можно даже править этот JSON руками в
блокноте, страница подхватит.

## Что покрыто

| Вкладка | Что вносим | Куда в коде |
|---|---|---|
| 🗺 Локация | энкаунтеры (общий / днём / ночью), уровни, дропы, заметка | `src/data/regions.ts`, `src/data/drops.js` |
| 🏪 Магазин | убрать/добавить предмет, цены, заметка | `src/data/shops.ts`, `src/data/items.ts`, `server/src/routes/economy.ts` |
| 💰 Цена предмета | новая цена + заметка | `src/data/items.ts`, `server/src/routes/economy.ts` |

**Формат дропа:** `вид:предмет:шанс:количество`, шанс — доля (0.05 = 5%).

## Обновление подсказок

В html вписаны списки локаций, магазинов и предметов (чтобы работало офлайн).
Если в игре появились новые — обнови:

```
npm run editor
```

Генератор только **читает** исходники и подставляет списки в html. Код игры он
не трогает. Правки в игру вношу я, вручную.
