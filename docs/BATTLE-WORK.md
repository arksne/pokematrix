## Правила работы

1. **Агентов НЕ использовать.** Они падают с HTTP 500 на апстриме (проверено трижды).
2. **Круг = правка → проверка → коммит.** Проверка: `npx tsc --noEmit` → `npm run test:vitest` → `npm run verify`.
3. **Долгие команды — через watchdog:** `pwsh -NoProfile -File tools\verify\watchdog.ps1 -TimeoutSec <N> -Quiet -Log "<path>" -Command "cd /d C:\Users\ARK\pokematrix && npm run verify"`.
4. **Пуш в `main` = деплой на Render.** Пушить только когда всё зелёное.
5. Перед `npm run verify` убивать зависшие node-процессы (`run.mjs`, `dist/index.js`).
6. Прогресс отмечать здесь галочками.

| 1 | У 6 ранних выходов `runEnemyTurnBody` пропали `return` | [x] |

| 6 | Семя Ужаса не вызывается вообще | [x] |
| 7 | `applyLeechSeedTick` пишет лечение в `S.activeWild.currentHp` вместо `S.wildCurHP` | [x] |
| 8 | Удачная поимка не вызывает `clearBattleState()` | [x] |
| 9 | Удачный побег не чистит `battle_state` и не переводит фазу в IDLE | [x] |
| 10 | Победа и поражение не переводят фазу VICTORY/DEFEAT → IDLE | [x] |
| 11 | Кнопки предмета/смены/побега не проверяют фазу | [x] |
| 12 | Смена покемона в бою с лидером запрещена вопреки спеке | [x] |

**Как решено:** введена `finishEnemyTurn()` — единая точка завершения хода врага.
Все шесть ранних выходов теперь делают `await finishEnemyTurn(); return;`.
Урон статусов и Семя Ужаса переехали из начала хода врага в момент «сразу после
действия владельца»: статус врага — в `finishEnemyTurn()`, статус игрока — в хвост
`useMove()`. Логи стали одной строкой на удар. Побег переписан под спеку: всегда
удачен, стоит покемону всех HP, при последнем живом — поражение.

**Проверено:** tsc чисто · 308/308 vitest · `npm run verify` — 107 PASS, 0 FAIL.

## Круг 7 — кланы с войнами (набросок)

### Данные
```ts
interface Clan {
  id: string;
  name: string;
  tag: string;          // 2-4 буквы
  emblem: string;       // emoji или URL
  founderId: string;
  createdAt: number;
  members: { userId: string; role: 'leader' | 'elder' | 'member'; joinedAt: number }[];
  stats: { wins: number; losses: number; warsPlayed: number };
}
```

### Эндпоинты (server)
- POST /clans — создать
- POST /clans/:id/join — вступить
- POST /clans/:id/leave — выйти
- POST /clans/:id/kick — кикнуть (только leader/elder)
- GET /clans — список с фильтром по уровню/активности
- GET /clans/:id — профиль
- POST /clans/:id/war/declare — объявить войну другому клану (24ч cooldown)
- POST /clans/:id/war/:warId/match — назначить матч (PvP-вызов внутри войны)
- GET /clans/:id/war — список войн и матчей

### Клиент (минимально)
- Экран «Мой клан» — профиль, участники, приглашения
- Экран «Список кланов» — с фильтром по уровню
- Экран «Войны» — активные и история

### Тех-задачи
- Миграция БД (новая таблица `clans`, `clan_members`, `clan_wars`)
- Авторизация (только лидер может распускать/объявлять войны)
- Защита от рейдов (cooldowns, минимальное число участников, анти-альт)

## Круг 8 — ~300 способностей из PokeAPI (набросок)

### Файл
Создать `src/data/abilities.ts` (или пополнить существующий) — массив:
```ts
interface AbilityDef {
  id: string;            // e.g. 'intimidate'
  nameRu: string;
  description: string;
  // Где срабатывает: 'onSwitchIn' | 'onDamage' | 'onEndTurn' | 'onMoveUse' | 'passive'
  triggers: ('onSwitchIn'|'onDamage'|'onEndTurn'|'onMoveUse'|'passive')[];
  // Что делает — хуки для движка
  effects: AbilityEffect[];
}
interface AbilityEffect {
  type: 'statStage' | 'immunity' | 'weather' | 'damageMod' | 'heal' | 'status' | 'switchOut' | ...;
  target: 'self' | 'foe' | 'allies' | 'all';
  params: any;
}
```

### Интеграция в движок
- `applyAbilityEffect(trigger, context)` в core.ts — диспатчер по типу триггера
- `getAbilityName(pokemon, isWild)` уже есть — добавить к нему поиск в новом словаре
- Все места, где есть хардкод про способности (`Intimidate`, `Levitate`, `Sturdy`, `Static`...) — заменить на диспатчер
- ~20 существующих → переписать как записи в abilities.ts
- ~280 новых — добавить записи (можно без полной логики — диспатчер вернёт no-op)

### Тех-задачи
- Тесты: каждая способность = минимум 1 тест на срабатывание
- Производительность: диспатчер не должен тормозить бой
- Документация: каждая способность описана 1 предложением по-русски
